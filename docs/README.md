# Portal educativo BI

Páginas públicas estáticas en `docs/`: inicio, BI, SQL, Power BI, proyectos, biblioteca y acerca.

Para publicar: Settings → Pages → Deploy from a branch → `main` → `/docs`, después del merge.

Las rutas existentes del repositorio se preservan. La biblioteca enlaza directamente a materiales de `main` para evitar duplicación de PDFs, datasets y guías.

Las pruebas finales de la publicación y enlaces públicos se realizan después del merge y la activación de Pages.
